# ЛКМ — рабочий центр проекта

Этот репозиторий уже используется для ЛКМ CRM. Документацию сайта и общие стандарты КП складываем сюда, но персональные данные клиентов и секреты сюда не загружаем.

## Документы

- [Аудит основного сайта и рекомендации по КП](docs/site-audit-2026-11-10.md)

## Как организуем материалы

- `docs/` — общие стандарты, анализ сайта, чек-листы качества, инструкции.
- `templates/` — обезличенные HTML/CSS-шаблоны КП без клиентских данных.
- `visual-guides/` — арт-дирекшн, требования к визуализациям и промпты без персональных данных.
- `projects/` — только обезличенные примеры и демонстрационные материалы; реальные клиентские файлы не размещать в публичном репозитории.
- Секреты CRM, API-ключи, PIN-коды, выгрузки и база данных остаются вне GitHub.

## Рабочий процесс для нового КП

1. Получить бриф, исходный расчёт и актуальный чертёж.
2. Сверить габариты, вход, окна, планировку и инженерные точки с чертежом.
3. Подготовить список подтверждённых характеристик и отдельно пометить неизвестные.
4. Создать визуализации только после фиксации геометрии; не добавлять неоговорённые окна, террасы или элементы.
5. Собрать HTML-КП из проверенного шаблона.
6. Проверить цены, состав работ, сроки, гарантию и исключения по действующим документам.
7. Проверить КП на телефоне и компьютере, затем опубликовать по согласованному адресу.

## Источник истины

GitHub-документы описывают стандарты и рабочие решения. Для конкретной сделки источником истины остаются актуальные утверждённые чертёж, расчёт/смета и договор. Если данные противоречат друг другу, не угадывать — зафиксировать расхождение и запросить подтверждение.
