# ЛКМ CRM

Лёгкая CRM ЛенКаркасМодуль: карточка клиента, стадии воронки, бриф, лента заметок и истории изменений. Открывается в любом браузере — на телефоне, планшете и компьютере. Ничего устанавливать не нужно.

## Как устроено

| Часть | Где живёт | Что это |
|---|---|---|
| Интерфейс | GitHub Pages (`index.html`) и копия на `lenkarkasmodul.shop/crm/` | Один HTML-файл без сборки |
| База и API | Хостинг reg.ru, `lenkarkasmodul.shop/crm/api.php` | PHP + SQLite, один файл |
| Данные | `crm/data/crm.sqlite` на хостинге | Закрыта от доступа из интернета |

Почему так: данные клиентов лежат на своём сервере в России, а не в публичном репозитории и не у зарубежного сервиса, который могут заблокировать. Ничего платного. Резервная копия — одна команда (`export`).

**В репозиторий НЕ кладём:** `server/config.php` (PIN-коды и ключи), базу, выгрузки клиентов. Они в `.gitignore`.

## Вход

Каждый сотрудник выбирает своё имя и вводит PIN. Список людей и PIN — в `server/config.php` на сервере. Вход запоминается на устройстве.

## Что умеет

- Доска по стадиям (на компьютере — колонки с перетаскиванием, на телефоне — вкладки стадий и список).
- Карточка: телефон (звонок в одно касание), источник, ответственный, следующий шаг и дата, модель, комплектация, сумма КП, бюджет, участок, оплата, сроки, кто решает, причина отказа, ссылка на чат Авито, **бриф**, комментарий.
- Смена стадии — одно касание по стадии в карточке.
- Лента: заметки + автоматическая история (кто, когда, что поменял).
- Сохраняются только изменённые поля — два человека, правящие одну карточку, не затирают друг друга.
- Автообновление каждые 20 секунд, поиск по имени/телефону/модели/адресу, фильтр «мои», «на сегодня».
- Демо без сервера: `index.html?demo`.

## API (для Claude и интеграций)

Все запросы — `POST` на `api.php`, тело JSON, `Content-Type: text/plain`.

```
{"action":"list","token":KEY}                         все сделки ({"since":ISO} — только изменённые)
{"action":"find","token":KEY,"q":"Даша"}              поиск по имени / телефону / ссылке на чат
{"action":"get","token":KEY,"id":12}                  карточка + лента
{"action":"save","token":KEY,"id":12,"changes":{...}} правка полей (id:null — новая карточка, можно "stage")
{"action":"move","token":KEY,"id":12,"stage":"EXECUTING"}
{"action":"note","token":KEY,"id":12,"text":"..."}
{"action":"export","token":KEY}                       полная копия базы
{"action":"import","token":CLAUDE_KEY,"deals":[...],"only_new":true}
```

Консольный клиент: `tools/lkm_crm.py` (адрес и ключ — в `~/.lkm_crm` или переменных `LKM_CRM_API`, `LKM_CRM_KEY`).

### Стадии

`NEW` Новый лид · `UC_MISSCALL` Н/О · `UC_X040U9` Общение · `PREPARATION` Квалифицирован · `UC_1T0IS0` КП без шоурума · `PREPAYMENT_INVOICE` Записан в шоурум · `EXECUTING` Был в шоуруме · `FINAL_INVOICE` КП и договор · `1` В производстве · `UC_NUPAHN` Отложенный спрос · `WON` Сдан · `LOSE` Отказ · `APOLOGY` Спам / не целевой

Коды совпадают с Битриксом, чтобы перенос и синхронизация шли без перекодировки.

## Установка

1. **Сервер.** В ISPmanager reg.ru → Менеджер файлов → в папке сайта создать папку `crm` → загрузить `api.php`, `config.php`, `.htaccess`, `index.html`. Проверка: `https://lenkarkasmodul.shop/crm/` открывает вход.
2. **GitHub Pages.** Репозиторий → загрузить `index.html`, `README.md`, `tools/` → Settings → Pages → Branch `main`, папка `/root` → Save. Через минуту CRM доступна по `https://<логин>.github.io/<репозиторий>/`.
3. **Перенос из Битрикса.** `BITRIX_HOOK=... python3 tools/bitrix_export.py deals.json && python3 tools/lkm_crm.py import deals.json`. Повторный запуск с `--only-new` докидывает только новые лиды.
